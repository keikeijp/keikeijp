# ロードマップ

「Spotify URL を貼って『この部分に合うサンプルを探してメロディまで DAW に置いて』」
「『この曲みたいなの作りたい』で DAW 上に一貫して実装」
に向けた段階的な計画。v0.1 は土台 (解析 / 検索 / MIDI / DAW ブリッジ / エージェントループ) が揃った状態。

## v0.2 — 「探す」を強くする
- [ ] CLAP (laion-clap) 埋め込みでテキスト → 音の検索 (`LocalLibrary(embedder=...)`)
- [ ] Freesound のプレビューをダウンロードしてローカルと同じ音響類似で再ランク
- [ ] 参照区間を HPSS / 帯域で分解し「この部分の "パッド" に近いもの」のようにパート別に検索
- [ ] Splice: 公式 API が無いため、MCP 連携またはブラウザ自動化で `SampleSource` を実装

## v0.3 — 「作る」を強くする
- [ ] 参照区間のコード進行推定 (chroma → テンプレートマッチ) を `analyze_reference_audio` に追加
- [ ] ドラムパターン生成ツール (`add_drum_pattern`: kick / snare / hat のグリッド指定)
- [ ] メロディの自動評価 (音域 / 跳躍 / リズム密度 を参照曲と比較して Claude にフィードバック)
- [ ] 生成物をレンダリング (fluidsynth) してもう一度 `analyze` に通す自己検証ループ

## v0.4 — 「DAW に置く」を強くする
- [ ] Ableton: `.als` (gzip XML) 生成でオーディオクリップも含めた完全なセットを出力
- [ ] Ableton: デバイス (Wavetable / Operator) のプリセット選択を `instrument_hint` から自動化
- [ ] REAPER: ReaScript (Lua) 生成で開いているプロジェクトに追記
- [ ] Logic / FL Studio 向けの MIDI + マーカー付き書き出し

## v1.0 — 一貫した制作体験
- [ ] DAW 内で動く UI (Max for Live デバイス / REAPER 拡張) からプロンプトを打てる
- [ ] 会話の継続 (「もっと暗く」「ベースを 8 分に」) — `ProjectPlan` を差分更新するツール群
- [ ] ローカル LLM / 安価モデルへの一部委譲 (サンプルの再ランクなど)

## 解決できない (しない) こと
- Spotify から音声を取得すること (規約違反)。ユーザーが権利を持つ音声ファイルを使う。
- 著作権のある楽曲の完全な複製。「雰囲気を参照する」用途に限定する。
